# 1. 実験の概要

## 目的と結果

2台のSBAT6を一台ずつ単独AP/STAとして動かすのではなく、EasyMeshの親子として構成することが目的だった。T6AをController、T6BをAgentとし、まずEthernet経由で制御面の参加を成立させた後、6 GHz無線BHに切り替えた。最終的にAgent側のEthernet配下へクライアントをつなぎ、親側ネットワークまでのL2延長を確認した。

| 項目 | 結果 | 証拠区分 |
|---|---|---|
| Controller/Agentの親子化 | Controller Distance 0、Agent Distance 1を観測 | 実機確認済み（当時の記録要約。原ログは非公開） |
| 6 GHz BH | 有線を外しても無線BHで接続を維持 | 実機確認済み（当時の記録要約） |
| L2延長 | Agent Ethernet側クライアントから上位側への疎通 | 実機確認済み（当時の記録要約） |
| MLO/160+160 | 5 GHz/6 GHz MLD設定とログ採取を保存。EHT320試験案は160+160を既知の成功ベースラインと記述 | 保存データから確認（オンエア詳細は未取得） |
| MLOの通信性能 | 一部カウンター・診断結果あり。全ての方向/継続時間を再構成できない | 未検証部分あり |
| EHT320 | 安全な試験スクリプト案とfailsafe案のみ確認。実機での成立記録なし | 未検証 |

## 成功判定を分ける

EasyMeshツリーに子機が現れること、6 GHz BHのradio associationがあること、IP到達性があること、Ethernetブリッジを越えてL2通信できることは別々に判定する。pingやSSHが失敗しても、それだけではMesh切断を意味しない。逆にMeshの親子表示だけでもL2転送成功とはいえない。
